Export

How the export cleans the file

The export copies only the selected pages into a new PDF. It does not copy data that these pages do not use. It removes the Illustrator private data: /PieceInfo, /LastModified, page thumbnails and XMP metadata. It keeps the artwork, images, layers and page boxes.
